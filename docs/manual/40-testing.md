\page ccweave-manual-40 Chapter 40: Testing

Test Glue ABI rejection, missing exports, capability verification, accessor
arity and error propagation, and ownership under sanitizers. Test IR
round-trips for every construct in both profiles and reject cross-profile
constructs.

Test manifests by generating, checking successfully, and detecting manual
drift. Test kernels with positive and negative transformations. Test Oeuph
for deterministic extraction, real budget stopping, and per-ruleset
statistics.

Run focused subsystem tests while developing, then run the complete CTest
suite before integrating a change.
